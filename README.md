# Viet Tam Blog - Do an giao dien

Website blog chu de tin nguong, tam linh, ton giao. Du an tap trung vao giao dien va tinh nang phia client, khong dung backend.

## Chuc nang da co

- Trang chu voi hero, nhom bai viet, bai viet moi va ban do pin dia diem tam linh.
- Nhom bai viet:
  - Dau an Phat giao
  - Thien chua giao
  - Tin nguong va ton giao khac
- Dang ky / Dang nhap (luu localStorage).
- Trang viet bai cho thanh vien da dang nhap (bai o trang thai cho duyet).
- Trang admin:
  - Dashboard thong ke.
  - Bang duyet bai, gan nhom bai truoc khi duyet.
  - Tu choi bai cho duyet.
- Trang chi tiet bai viet:
  - Binh luan cho thanh vien da dang nhap.
  - Goi y bai viet tiep theo (ngau nhien).

## Tai khoan admin mac dinh

- Email: `admin@viettam.local`
- Mat khau: `123456`

## Cau truc du lieu demo

- `data/demo-posts.json`: du lieu bai viet seed ban dau.
- `content/posts/`: thu muc bai viet markdown demo.
- `content/images/`: thu muc anh (ban co the bo sung sau).

## Chay du an

Chi can mo `index.html` bang Live Server (khuyen nghi) hoac server tinh bat ky.

Vi du voi VS Code Live Server:

1. Chuot phai `index.html`.
2. Chon `Open with Live Server`.
